Upload

One uploader takes images, masks, models and saved sessions, and sorts them for you.

Upload Images, Masks and Models
File uploader
Drag & drop
Takes images (.tif, .tiff, .png, .jpg, .jpeg), masks (.tif, .tiff, .npy), model weights (.pt, .pth), a Cellpose settings file (.csv) and a saved session (.zip). Masks without an image with a matching name are skipped.
Mask suffix
Text box
Pairs masks with images by filename. With the default _masks, sample1_masks.tif pairs with sample1.tif.
Resize (512x512)
Checkbox
On by default. Scales each image and mask to be 512 x 512 pixels, while maintaining their proportions. This can keep the app responsive if you have limited memory. Cell measurements are converted back to the original image's dimensions.
Use demo data
Button
Loads an example set so you can test out the workflow.
Uploaded images
Remove selected images
Button
Select images in the table above, then remove them by clicking this button.

Segmentation Controls Tab
Predict masks with Cellpose Popover

The five settings sit under Cellpose hyperparameters. Sizes are in pixels of the image as loaded into Mycol, so after any 512 resize.

Select model
Dropdown
Cyto3, Cyto2, Cyto, Nuclei, or Fine-tuned Model (uploaded or trained this session, and selected by default when available).
Generate
Button
Segments the image on screen. Replaces all of its masks and clears their class labels. Can be undone.
Batch generate
Button
The same for every image inside the Batch call range slider below it. Cannot be undone.
Mean cell diameter
Number
Typical cell width in pixels. At 0, Cellpose uses the cell size the model was trained on; it does not estimate it.
Cell probability threshold
Number
−2 to 2. How sure Cellpose must be that a pixel belongs to a cell. Higher gives fewer, smaller masks.
Flow threshold
Number
−2 to 2. Raise if cells are missing; lower to remove badly predicted mask shapes.
Minimum cell size
Number
Discards masks smaller than this many pixels, a quick way to drop debris.
Niter
Number
0 to 2000. Higher values favour identification oflong, thin cells such as filaments. At 0, Cellpose chooses a value from the cell diameter.
Predict masks with boxes Popover

MobileSAM, for segmenting chosen cells.

Draw box
Mode B
Drag a box around cells you want segmented.
Generate masks from boxes
Button G
MobileSAM predicts one mask inside each box.
Manually edit masks Popover
Freehand
Mode F
Hold and trace an outline; releasing fills it as a mask.
Ellipse
Mode E
Drag a box and to draw an ellipse (a circle if the box is square).
Split masks
Mode S
Drag a line all the way through a mask to cut it in two.
Join masks
Mode J
Lasso around masks. Touching masks that are entirely inside the lasso are merged.

3

Train

Choose Cellpose or DenseNet in step 1; the settings in step 3 change to match.

Step 2 - Select images to train on
Image table
Table select
All images are ticked by default. Cellpose learns from their masks, DenseNet from their labelled cells.
Step 3 - Cellpose settings
Base model
Dropdown
The model to start from: cyto, cyto2 (default), cyto3 or nuclei. scratch starts from nothing and needs far more data.
Max epochs
Number
1 to 1000 passes through the training images. Cellpose runs all of them and keeps the final model.
Learning rate
Number
How much the model changes with each update. Lower trains more slowly but more steadily.
Weight decay
Number
A penalty applied throughout training that discourages the model from memorising your images.
Min cells per image
Number
Images with fewer masks are left out. The step 4 summary shows how many.
Batch size
Dropdown
8 to 64 images used for each update, each as a 224 × 224 pixel crop. Larger is faster but needs more memory.
Images per epoch
Dropdown
All uses each image once per epoch; a number samples that many at random.
Optimise hyperparameters
Checkbox
On by default. After training, searches for the cell probability threshold, flow threshold, Niter and minimum cell size that best reproduce your masks, using up to 40 training images. The winners are applied on the Annotate page automatically. Diameter is not tuned.
Optimisation iterations
Slider
10 to 60 combinations to try. More can find better settings but takes longer.
Train / test split
Slider
The share of images used for training. The rest are never trained on and are used for the step 5 plots.
Step 3 - DenseNet settings
Input size
Dropdown
64, 96 or 128 pixels. Each cell is cut out and scaled to fit this square, so the model cannot use cell size to tell classes apart. Larger keeps more detail but trains more slowly.
Batch size
Dropdown
Cells used for each update.
Max epochs
Number
1 to 500. An upper limit: training stops after 30 epochs without improvement and keeps the best model.
Train / validation split
Slider
The share of labelled cells used for training. The rest choose the best model and are used for the step 5 plots.
Step 4 - Train the model

Only one model can train at a time.

Training set summary
Status
Shows how many images or cells will be used and how they are split.
Fine-tune buttons
Button
Start training in the background. DenseNet needs at least two classes with two or more labelled cells each.
View Training Log
Expander
Live progress while a job runs. Cellpose then shows a View Validation Log while it scores the new model.
Step 5 - Review model training
How do I interpret these graphs?
Popover
Explanations of each plot.
Tested hyperparameters
Table
Every combination tried by Optimise hyperparameters and its score. The best is automatically applied on the annotations page.
4

Phenotypes

Plot cell descriptors to compare class distributions.

Choose what to plot
Image table
Table select
Select the images to include in the plots.
Choose classes to compare
Multiselect
Each class becomes one group in the plots. Cells with no class are grouped as Unlabelled.
Choose cell descriptors to compare
Segmented control
One plot per descriptor. Attribute Information explains each one.
Plot options
Plot type
Pills
Violin shows the full spread of each class; Bar shows the mean with standard deviation error bars.
Overlay datapoints
Option pill
Draws individual datapoints on the plot, showing sample size and outliers.
Convert to distance
Option pill
Reports size descriptors in real units. Enter the Pixel size of your original images and a Unit (default µm). Shape and colour descriptors have no units and are unchanged.

Tables

Cell metrics
Checkbox

Trained Models

Available once a model has been trained or uploaded.

Cellpose model
Checkbox
The trained model, its training images and masks, plots, and settings files. The cellpose_inference_hyperparameters.csv inside can be uploaded later to restore its segmentation settings.
DenseNet model
Checkbox
The trained model, its training images, plots and settings.
Session Restore
Save Session
Checkbox
Adds mycol_saved_session.zip; upload it, without unzipping, to restore your session.
